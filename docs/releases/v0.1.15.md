### Added

- A custom Wayland popup panel opened by left-clicking the tray icon.
- Inline device details and a separate Settings page inside the same panel.
- Close the panel with Escape, its close button, or a click outside it.

### Changed

- Translate the README, protocol notes, and all published release descriptions into English.
- Keep Plasma's native context menu available on right-click as a fallback.

### Fixed

- Device details and Settings no longer use overlapping cascading menus in the default panel.
- Reserve extra spacing before submenu arrows in the native fallback menu.
- Keep the expanded device selected when readings refresh or the device list changes.
