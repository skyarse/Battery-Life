### Добавлено

- Первый опубликованный AppImage Battery Life для KDE Plasma на Wayland.
- Список беспроводных устройств в трее и отдельное окно с подробностями через `--window`.
- Проверка заряда каждые 30 секунд через Linux, BlueZ, UPower и протоколы поддерживаемых USB-приёмников.
- Диагностика устройств и правила udev для доступа к приёмникам.
- Автоматическая сборка AppImage и публикация новых версий через GitHub Actions.

### Изменено

- Необнаруженные устройства скрываются из списка.

### Исправлено

- Для ZAOPIN Z2 Max учтены ответы используемого 8K-приёмника.
- Для MCHOSE V9 PRO различаются работа от батареи, зарядка и выключение. Показания отмечены как приблизительные.
- В подменю показывается время последнего ответа устройства.
